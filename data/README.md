# Data

`IPL.csv` is not stored in this repository because it is about 107 MB, above GitHub's 100 MB file limit.

## Download

- Kaggle dataset: "IPL Dataset" (`IPL.csv`). It is listed under **Input** on the Kaggle notebook [Indian Premier League Analysis (2008-2025)](https://www.kaggle.com/code/arbazkhan971/indian-premier-league-analysis-2008-2025).
- Original ball-by-ball source: [Cricsheet](https://cricsheet.org).

Save the file as `data/IPL.csv`, then follow "How to reproduce" in the main README.

## File description

One row per delivery, 64 columns (match details, batter, bowler, runs, extras, wickets, toss, venue, season and cumulative statistics).
